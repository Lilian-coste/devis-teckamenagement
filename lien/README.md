# /lien — Page de liens Teck (type « Linktree »)

URL : **https://devis.teckamenagement.fr/lien**
Usage : lien unique à mettre dans les bios (Instagram, etc.).

## Personnaliser

Tout est dans `index.html`, à la fin du fichier, entre les repères **« ZONE À MODIFIER »** :
- `SETTINGS` : sous-titre, pied de page.
- `LINKS` : la liste des boutons (label + url + icône). Ordre = ordre d'affichage.

Style : verre dépoli, icônes en couleur, mise en page centrée (logo en haut, copyright en bas).

## Images

Dans `assets/` : `bg-desktop.jpg`, `bg-mobile.jpg` (mêmes fonds que le simulateur), `logo.png` (logo blanc overlay).

Après modif : commit + push sur `main` → Vercel redéploie automatiquement.
