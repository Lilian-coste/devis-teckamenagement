# Copy de devis

**Le texte s'écrit ICI, avant d'entrer dans le code.**

Une page de quiz, une page de résultat, un simulateur, une affiche portent des mots qui
sont de la copy autant que ceux d'un email. Écrits directement dans le code, ils
n'existent nulle part : ni cherchables, ni relisables, ni réutilisables dans une
publicité six mois plus tard.

Donc le texte naît dans ce fichier, puis on le porte dans le code. Le code devient le
rendu d'un texte qui existe ailleurs, plutôt que sa prison.
