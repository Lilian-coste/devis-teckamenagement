Les deux boutons d’ouverture sont un essai. La syntaxe du lien sms: n’est pas la même partout : iOS accepte &body=, le reste attend ?body=. Dites-nous lequel des deux remplit vraiment le message sur votre téléphone, nous supprimerons l’autre.

[LIEN] reste à remplacer dans le message 3 : c’est le lien de réservation de créneau, il n’est pas encore arrêté.

La seule variable des messages est {{prenom}}. Ici elle affiche « Béatrice ».

La page se personnalise par son adresse, ?prenom=…&tel=…, avec &nom=… et &commune=… pour la fiche du haut.
